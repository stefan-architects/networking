## 📌 Project Overview
This repository documents my hands‑on practice while learning VPC Flow Logs through guided lessons from two YouTube tutorials. As part of this learning process, I created two EC2 instances to capture, inspect, and troubleshoot network traffic, using two IAM roles and permissions specifically configured for working with VPC Flow Logs. Each lesson will be provided separately to clearly show the progression of concepts and exercises.

### 📺 Sources
- [Mini Project - Learn how to use VPC Flow logs to diagnose network issues](https://www.youtube.com/watch?v=4HvwQ1uoWEA)
- [AWS VPC Flow Logs EXPLAINED! Capture & Analyze Traffic Like a Pro!](https://www.youtube.com/watch?v=j4ab0R_XPTA)
